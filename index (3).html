Personal assistant API¶

Sprint 06 builds on the student’s Sprint 05 documentation sandbox at dulguun03/software-project-documentation. The reference describes the code that exists: a local, in-memory HTTP sandbox. Calendar execution increments a simulated write counter. It makes no Google, OAuth, AI-inference, or callback requests.
